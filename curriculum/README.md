# Socket.IO カリキュラム

このカリキュラムでは、Socket.IOをゼロから習得できるように、段階的に学習を進めます。

## 📚 カリキュラムの進め方

各レッスンは独立しており、順番に進めることで確実にスキルを習得できます。
各レッスンには以下の要素が含まれています：

- **メリット**: その機能を使うことで得られる利点
- **デメリット**: 注意すべき点や制限事項
- **技術的原理**: 内部でどのように動作しているか
- **ユースケース**: 実際にどのような場面で使うか
- **実装例**: 実際に動くコード例

## 🎯 学習の流れ

1. [全体像と技術的原理](./01-overview.md) - Socket.IOの基礎を理解する
2. [基本的な接続](./02-basic-connection.md) - クライアントとサーバーを接続する
3. [イベントの送受信](./03-events.md) - メッセージをやり取りする
4. [ブロードキャスト](./04-broadcast.md) - 複数のクライアントにメッセージを送る
5. [ルーム](./05-rooms.md) - クライアントをグループ化する
6. [ネームスペース](./06-namespaces.md) - アプリケーションを論理的に分割する
7. [ミドルウェア](./07-middleware.md) - 認証と前処理を実装する
8. [エラーハンドリング](./08-error-handling.md) - エラーを適切に処理する
9. [再接続とバッファリング](./09-reconnection.md) - 接続の安定性を向上させる
10. [スケーリング](./10-scaling.md) - 複数サーバーで動作させる

## 🚀 はじめに
